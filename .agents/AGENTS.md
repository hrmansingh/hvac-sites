# NorthDemand Project Rules & AI Agent Directives

## Design & UI/UX Standards
1. **Design System Adherence**: All UI updates must follow the `.agents/skills/design-system/SKILL.md` guidelines.
2. **Visual Excellence**:
   - Every interface must feel premium, modern, and high-converting.
   - Use curated colors, glassmorphism backdrop filters, clean gradients, and subtle micro-animations.
3. **Mobile First & Responsiveness**:
   - Ensure 100% responsiveness across mobile (320px+), tablet (768px+), and desktop viewports.
   - All interactive elements (buttons, inputs, links) must have at least 44px x 44px tap target size.
   - Prevent any horizontal page scrolling (`max-width: 100%`, `overflow-x: hidden`).
4. **Typography & Layout**:
   - Use dynamic fluid typography (`clamp()`) with modern font pairs (`DM Sans`, `Libre Baskerville`).
